# 2. El método: 4 reglas <span class="en">· The method: 4 rules</span>

:::bi
1. **Recordar, no releer.** Después de leer un tema, **cierra el material** y escribe todo lo que recuerdas. Luego compara. Esto vale más que leer 3 veces.
2. **Español → inglés.** Explica cada idea en voz alta **en español**, y después **di la misma idea en inglés** con las plantillas de la sección 6.
3. **Bloques de 25 minutos.** Estudia 25 minutos y descansa 5 (técnica Pomodoro). Máximo 3 bloques seguidos.
4. **Repasar en días distintos.** Cada tema aparece **3 veces** en el plan: el día que lo aprendes, un repaso corto y la práctica final.
:::en
1. **Recall, don't reread.** After reading a topic, **close the material** and write everything you remember. Then compare. This is worth more than reading 3 times.
2. **Spanish → English.** Explain each idea out loud **in Spanish**, then **say the same idea in English** using the templates in section 6.
3. **25-minute blocks.** Study 25 minutes and rest 5 (Pomodoro technique). Maximum 3 blocks in a row.
4. **Review on different days.** Each topic appears **3 times** in the plan: the day you learn it, a short review and the final practice.
:::

# 4. Listas para memorizar y trucos <span class="en">· Lists to memorize and tricks</span>

:::div two

:::div card geo
### 🌋 Geología <span class="en">· Geology</span>

- **4 capas**: Corteza → Manto → Núcleo externo (líquido) → Núcleo interno (sólido). *Crust → Mantle → Outer core → Inner core.*
- **Corteza**: 5 km oceánica · 70 km continental. *5 km oceanic · 70 km continental.*
- **Ondas**: P pasan todo · **S solo sólidos**. *P go through everything · S only solids.*
- **3 límites**: convergente (chocan) · divergente (se separan) · transformante (se deslizan).
- **3 meteorizaciones**: mecánica (hielo) · química (ácido, óxido) · biológica (raíces).
- **Horizontes O-A-B-C-R**: "Osos Amables Bailan Con Ritmo" · "Old Ants Bring Cold Rocks".
- **Mineral = N-I-S-C-C**: Natural, Inorgánico, Sólido, Composición química, Cristal.
- **Rocas**: Ígnea (fuego) · Sedimentaria (capas, fósiles) · Metamórfica (calor + presión).
- **Granito** = intrusiva · **Basalto/obsidiana** = extrusiva · **Mármol** = metamórfica.
:::

:::div card cell
### 🦠 La Célula <span class="en">· The Cell</span>

- **3 postulados**: "**hechos de** células · **unidad** básica · **vienen de** otra célula". *"made of · unit · come from".*
- **Niveles**: Célula → Tejido → Órgano → Sistema → Organismo. *"Can Tigers Only Swim Over?"*
- **Pro** = sin núcleo (bacterias) · **Eu** = con núcleo (el resto).
- **Solo plantas**: pared, cloroplastos, vacuola central grande.
- **8 organelos**: barrera → membrana · ADN → núcleo · energía → mitocondria · fotosíntesis → cloroplasto · proteínas → ribosoma · almacena → vacuola · enzimas → lisosoma · movimiento → cilios/flagelos.
- **Virus** = cápside + ADN/ARN; lítico (revienta) · lisogénico (se esconde).
- **Asexual**: fisión binaria (2 iguales) · gemación (brote) · fragmentación (pedazos) · esporas.
- **Estable → asexual · Cambiante → sexual.**
:::

# 6. Plantillas para escribir en inglés <span class="en">· English writing templates</span>

:::bi
En el examen pasado perdiste **25.5 puntos** en preguntas escritas. La mayoría no fue por no saber, sino por **no explicar** el "por qué". Copia estas plantillas y llena los espacios.
:::en
On the past tests you lost **25.5 points** on written questions. Mostly not for not knowing, but for **not explaining** the "why". Copy these templates and fill in the blanks.
:::

:::div tight

| Tipo de pregunta · Question type | Plantilla · Template |
|---|---|
| **Explain why** (explica por qué) | ___ is better for ___ **because** ___. **For example,** ___. |
| **Compare** (compara) | ___ are ___, **while** ___ are ___. **Both** ___ and ___ are ___. |
| **Process / steps** (proceso) | **First,** ___. **Then,** ___. **Next,** ___. **Finally,** ___. |
| **Two cycles + difference** | **In the lytic cycle,** the virus ___. **In the lysogenic cycle,** ___. **The main difference is that** ___. |
| **Landform** (relieve) | The ___ is formed mainly by **constructive / destructive** forces of ___. The driving agent / boundary is ___. First, ___. Then, ___. Finally, ___. The most common rock is ___ **because** ___. |
| **Role** (papel) | In ecosystems, microorganisms ___ (decompose / recycle / fix nitrogen). **For example,** ___. In human health, they ___, **but** some ___ (cause diseases like ___). |
| **Practice** (práctica) | One soil conservation practice is ___. The farmer ___. **This protects the soil because** ___. |
| **Similarity / difference** | **A similarity is that both** ___. **A difference is that** ___, **whereas** ___. |

:::

:::bi
**Conectores**: *because* (porque) · *so / therefore* (por eso) · *while / whereas* (mientras que) · *both* (ambos) · *however* (sin embargo) · *for example* (por ejemplo) · *first, then, next, finally* (primero, luego, después, finalmente).
:::en
**Connectors**: *because* · *so / therefore* · *while / whereas* · *both* · *however* · *for example* · *first, then, next, finally*.
:::

:::box exam ✍ La regla de oro · The golden rule
:::bi
Mira los **puntos** entre paréntesis: "(3 pts: 1 pt correctness for each type; 1 pt completeness)" te dice **exactamente** qué escribir. Si vale 3 puntos, escribe **al menos 3 ideas**. Nunca dejes "no answer": escribe lo que sepas con la plantilla.
:::en
Look at the **points** in parentheses: "(3 pts: 1 pt correctness for each type; 1 pt completeness)" tells you **exactly** what to write. If it's worth 3 points, write **at least 3 ideas**. Never leave "no answer": write what you know with the template.
:::

# 7. Estrategias por tipo de pregunta <span class="en">· Strategies for each question type</span>

:::bi
**Selección única**: subraya las **palabras en negrita** de la pregunta: son las pistas (*freezes and expands* → mecánica; *acid, dissolve* → química; *powder* → raya). Elimina primero las opciones absurdas.

**Pareos**: haz primero las que estás **seguro**. **Tacha** cada letra usada (no se repiten). Busca la palabra clave en negrita.

**Respuesta corta**: usa la **palabra exacta** del vocabulario. No confundas **tipos** (de roca, de célula) con **capas** o **propiedades**.

**Escritura**: usa la plantilla; responde **cada parte** que pide la rúbrica; da **un ejemplo**.
:::en
**Multiple choice**: underline the **bold words** in the question: they are the clues (*freezes and expands* → mechanical; *acid, dissolve* → chemical; *powder* → streak). Eliminate absurd options first.

**Matching**: do the ones you're **sure** about first. **Cross out** each letter you use (no repeats). Look for the bold keyword.

**Short answer**: use the **exact word** from the vocabulary. Don't confuse **types** (of rock, of cell) with **layers** or **properties**.

**Writing**: use the template; answer **every part** the rubric asks for; give **an example**.
:::
